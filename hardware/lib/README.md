# Local KiCad libraries

- `Espressif.pretty`: the ESP32-S3-MINI-1 footprint, from Espressif's
  [kicad-libraries](https://github.com/espressif/kicad-libraries).
- `rc_control.kicad_sym` (SX1280, AT2401C, 2450FM07D0034) and
  `AnyLeaf.pretty` (2450FM07D0034): from AnyLeaf's
  [elrs-hardware](https://github.com/AnyLeaf/elrs-hardware), MIT licence,
  Copyright 2023 AnyLeaf LLC. Changes: SX1281 renamed SX1280 (same pinout),
  GND pins typed power input, the SX1280's regulator pins typed passive.
