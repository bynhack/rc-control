# X2201 電路板迭代路徑

終極目標是 ALL IN ONE：電調、ELRS、OpenIPC 圖傳、計圈全部在一塊板上。

做法是先把已有、已跑通的東西整合起來，每一步只驗證一件新事情。階段 2 之前不自製接收機或圖傳。階段 1 的有刷電調和 5V BEC 都做在主板上，不外接電調。

| 階段 | 內容 | 狀態 |
|---|---|---|
| 0 接線驗證 | 不打板，用 S3 開發板接線 | 全部通過（2026-11-13） |
| 1 主板 | 電池只進主板。板載電調（DRV8874）驅動 260 馬達，板載 BEC（5V 3A）供 ESP32、EP2、舵機。另接圖傳、陀螺儀、IR，按鈕開關機 | v10 已畫（76×20），尚未打板 |
| 2 ALL IN ONE | ELRS、OpenIPC、計圈和階段 1 的電調、BEC 合成一塊 | 目標，尚未設計 |

## 車的組成

電機、舵機、接收機已確定，電調做在主板上。ZERO-Z 和成品電調模組都不再使用：

- 電機：260 有刷馬達，2S（7.4V，500 mAh）。
- 舵機：17g 三線標準舵機。
- 接收機：EP2 2400RX，CRSF 接到 S3。
- 電調：主板上的 TI DRV8874（4.5–37V，峰值 6A，內建限流和過流、過熱保護），限流設在約 4.9A。原本參考的 RZ7886 立創沒有 SOP-8 現貨，而且規格書沒寫保護功能，所以不用。

## 階段 0：接線驗證

EP2 → CRSF → S3 → PWM → 電調。電池主線進電調，電調 BEC 的 5V 給 S3 和 EP2。訊號線全接、一起上電，EP2 不會卡死。2026-11-13 階段 0 全部通過。

原本卡死的原因是 EP2 的 TX 焊盤直接接到電調的第 1 路，電調開機時把它拉低。改成只接 S3 後，這個條件就不存在了。

## 階段 1：主板

2026-11-16 定案：電調做在主板上，不買外接電調。之前的外接電調方案要多拉電調電源線、訊號線，還要處理有沒有 BEC 的問題，接線太繁瑣。板子是 `x2201-carrier-v10`。

```
電池 → 主板 BAT+/BAT− → Q1 防反接 ─┬→ DRV8874（電調，限流 4.9A）→ ZH2.0 → 260 馬達
                                     ├→ LMR51430 5V 3A 降壓（BEC）→ S3、EP2、舵機、風扇、IR
                                     └→ 電量偵測、圖傳（S3 的 IO6 開關）
S3 IO7 / IO4 → DRV8874 前進 / 後退
ZH1.5 按鈕 → 按一下開機，再按一下關機（S3 用 TX 保持電源）
```

- **電調**：DRV8874，PWM 模式，兩隻 GPIO 控制：一高一低為前進或後退，兩腳都高是煞車，兩腳都低是惰行。限流約 4.9A，起步和卡住時保護馬達、插頭和電池。
- **BEC**：LMR51430，輸入 4.5–36V，輸出 5.0V，連續 3A。不用線性穩壓，因為 2S 滿電時每 1A 要燒掉約 3.4W。
- **開關**：不自鎖按鈕。按下時電池經二極體拉高 BEC 的 EN，S3 開機後用 TX 接著拉住 EN。再按一下，S3 把 TX 拉低就關機。關機後 BEC 停止輸出，DRV8874 休眠。
- **電池接反**：Q1 是低側 N-MOS，接反時整塊板斷開。v9 的 Q1 把 drain、source 接反了，v10 已改正。
- **控制器**：自己焊上的 ESP32-S3 SuperMini，USB-C 伸出板外。只插 USB 時，S3 和 EP2 有電，可以燒錄。
- **板形**：76×20 mm，沿車身縱向擺放。插座全部是側插的 ZH1.5，馬達插座是 ZH2.0，插口都朝外。不打螺絲孔，由外殼固定。
- GPIO 對照表見 `x2201-carrier-v10/README.md`。SuperMini 板邊沒有引出 IO14–18，所以有幾隻腳位和 v9 不同。

過關條件：裝車後每次上電都能用，前進、煞車、倒車和轉向都正常，陀螺儀讀得到，IR 能被終點拱門辨識。按鈕能正常開機和關機，關機後馬達不出力。

韌體要跟著改：油門從一條舵機脈衝改成 H 橋兩腳控制；開機後立刻把 TX 設成高電位；用 RX 讀按鈕。階段 0 的程式不能直接用在這塊板上。

## 階段 2：ALL IN ONE

等階段 1 完成才開始，這裡只記方向。

- 電調和 5V BEC 沿用階段 1。
- ELRS 上板，可參考 `archive/x2201-carrier-v5`、`-v6`。
- OpenIPC 圖傳上板，v5 有 Thinker 影像板 + BL-M8812EU2 的電路可參考。
- 計圈和陀螺儀沿用階段 1。

v6 的教訓：一次整合太多，初版風險過高。所以開始前要先分別驗證電調、ELRS、圖傳這幾塊，最後才合成一塊。馬達雜訊對射頻和影像的干擾、散熱也要先評估。
