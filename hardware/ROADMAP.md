# X2201 電路板迭代路徑

終極目標是 ALL IN ONE：電調、ELRS、OpenIPC 圖傳、計圈全部在一塊板上。

做法是先把已有、已跑通的東西整合起來，每一步只驗證一件新事情。階段 3 之前不自製電調、接收機或圖傳。

| 階段 | 內容 | 狀態 |
|---|---|---|
| 0 接線驗證 | 不打板，用 S3 開發板接線 | 進行中 |
| 1 整合板 | S3 上板，其餘全部用插頭，加 IR 計圈 | 等階段 0 |
| 2 延遲上電 | 只有 S3 隔離無效時才做 | 備案 |
| 3 ALL IN ONE | 電調、ELRS、OpenIPC、計圈整合 | 目標，尚未設計 |

## 階段 0：接線驗證

驗證 EP2 → CRSF → S3 → PWM → 電調，能不能避開 EP2 上電卡死。步驟見 [HANDOFF.md](../HANDOFF.md)，韌體在 `firmware/elrs-bench`。

- 電調上電 10 次都正常：進階段 1。
- 仍會卡：不打階段 1 的板，直接進階段 2。

## 階段 1：整合板

在 v8 的基礎上修改，板上零件全部貼片，不用手焊。

- S3-MINI-1 貼片，S3 隔在 EP2 和電調中間，由 GPIO8、GPIO7 輸出 S1、S2。
- EP2 不上板，只用 J2（ZH1.5 4P）連接：TX 到 GPIO13、RX 到 GPIO14、5V、GND。
- 拿掉 v8 的 EP2 焊盤和延遲電路（Q1、C1、R1、D1）。
- IR 計圈由 S3 驅動，LED 接 J5。
- v8 已有的電量偵測、圖傳插座、風扇插座、USB-C 保留。

過關條件：裝車後每次上電都能用，控制正常，IR 能被終點拱門辨識。

## 階段 2：延遲上電（備案）

條件：S3 隔開 EP2 和電調後仍會卡死。

- 回到 EP2 維持 PWM、經板子直接接電調（v8 的方案 A）。
- 加上 EP2 的 5V 延遲電路。這個 RC 電路還沒實測，手動開關的做法已實測有效。
- EP2 同樣只用 J2 連接。

## 階段 3：ALL IN ONE

等前面的階段完成才開始，這裡只記方向。

- 有刷電調（2S，260 馬達）和 BEC 上板。
- ELRS 上板，可參考 `archive/x2201-carrier-v5`、`-v6`。
- OpenIPC 圖傳上板，v5 有 Thinker 影像板 + BL-M8812EU2 + 5V 3A 降壓的電路可參考。
- 計圈沿用階段 1。

v6 的教訓：一次整合太多，初版風險過高。所以開始前要先分別驗證電調、ELRS、圖傳這幾塊，最後才合成一塊。馬達雜訊對射頻和影像的干擾、散熱也要先評估。

## 目前的板子

| 路徑 | 狀態 | 用途 |
|---|---|---|
| `x2201-carrier-v8` | 暫緩，EP2 焊盤要改成插頭 | 階段 1、2 的基礎 |
| `transponder` | 獨立 IR 應答器 | 其他車計圈 |
| `archive/` | v3～v7 | 只供參考 |
