# X2201 電路板迭代路徑

終極目標是 ALL IN ONE：電調、ELRS、OpenIPC 圖傳、計圈全部在一塊板上。

做法是先把已有、已跑通的東西整合起來，每一步只驗證一件新事情。階段 2 之前不自製電調、接收機或圖傳。階段 1 外接一塊不帶 BEC 的成品有刷電調，5V 由主板自己做。

| 階段 | 內容 | 狀態 |
|---|---|---|
| 0 接線驗證 | 不打板，用 S3 開發板接線 | 全部通過（2026-11-13） |
| 1 主板 | 電池進主板，主板再供外接電調（無 BEC 版）。板載 BEC（5V 3A）供 ESP32、EP2、舵機。另接圖傳、陀螺儀、IR | v10 已畫（76×20），尚未打板 |
| 2 ALL IN ONE | ELRS、OpenIPC、計圈和階段 1 的電調、BEC 合成一塊 | 目標，尚未設計 |

## 車的組成

電機、舵機、接收機、電調已確定。ZERO-Z 不再使用：

- 電機：260 有刷馬達，2S（7.4V，500 mAh）。
- 舵機：17g 三線標準舵機。
- 接收機：EP2 2400RX，CRSF 接到 S3。
- 電調：RZ7886 成品有刷電調模組，**無 BEC 版**（21×12×5.6 mm，1.3 g，2–3S，耐壓 13.5V，持續 7.5A，峰值 15A）。控制邏輯和一般 RC 車相同，S3 送標準舵機脈衝。同款還有帶 BEC（5V 1A）的版本，這裡不用。

## 階段 0：接線驗證

EP2 → CRSF → S3 → PWM → 電調。電池主線進電調，電調 BEC 的 5V 給 S3 和 EP2。訊號線全接、一起上電，EP2 不會卡死。2026-11-13 階段 0 全部通過。

原本卡死的原因是 EP2 的 TX 焊盤直接接到電調的第 1 路，電調開機時把它拉低。改成只接 S3 後，這個條件就不存在了。

## 階段 1：主板

2026-11-16 定案，取代 11-13 的板載 H 橋方案。電調外接，用不帶 BEC 的模組，5V 由主板的降壓供應。階段 0 驗證的是同款電調的帶 BEC 版，訊號和控制邏輯相同，只有 5V 的來源不同。

```
電池 → 主板 W1/W2 → Q1 防反接 ─┬→ W3/W4 → 外接電調（無 BEC）→ 260 馬達
                                ├→ U4 5V 3A 降壓（BEC）→ S3、EP2、舵機、風扇、IR
                                └→ 電量偵測、圖傳（S3 的 IO6 開關）
S3 IO7 → P1 電調訊號（S、G 接，V 不接）
J6 開關 → 降壓的 EN
```

- **為什麼不用帶 BEC 的電調**：帶 BEC 版的 5V 1A 是線性穩壓。2S 滿電時每 1A 要燒掉約 3.4W，舵機一卡住就超過 1A，S3 和 EP2 會跟著掉電。主板的 LMR51430 是開關降壓，可連續輸出 3A。
- **BEC**：LMR51430，輸入 4.5–36V，輸出 5.0V（0.6V ×（1 + 22k/3k）），電感 4.7µH。
- **開關**：J6 只控制降壓的 EN，馬達電流不經過它。關掉後沒有 5V：S3 不出脈衝，電調不轉；IO6 沒電，圖傳也斷。電調本身仍接在電池上，待機電流以模組規格為準。
- **電池接反**：Q1 是低側 N-MOS，drain 接電池負極，source 接主板 GND。電池接反時，主板和電調一起斷開。v9 的 Q1 把這兩腳接反了，v10 已改正。
- **USB**：和 BEC 之間用二極體隔開，可以同時插。只插 USB 時，只有 S3 和 EP2 有電，舵機和圖傳不從 USB 取電。
- **板形**：76×20 mm，沿車身縱向擺放。ESP32 在左端，天線朝外；插座排在兩條長邊上；電池、防反接和降壓在右端。不打螺絲孔，由外殼固定。
- GPIO 和 v9 相同：IO7 油門脈衝、IO8 舵機、IO9 電量、IO13/14 CRSF、IO6 圖傳電源、IO10/11 圖傳 UART、IO15 IR、IO16/17/18 陀螺儀。

過關條件：裝車後每次上電都能用，前進、煞車、倒車和轉向都正常，陀螺儀讀得到，IR 能被終點拱門辨識。開關關掉後，5V 和圖傳都斷電，馬達不出力。

韌體：油門仍是一條舵機脈衝（IO7），和階段 0 相同，不用改成 H 橋控制。

## 階段 2：ALL IN ONE

等階段 1 完成才開始，這裡只記方向。

- 5V BEC 沿用階段 1。有刷電調改成做在板上（RZ7886 這類集成 H 橋），上板前要先單獨驗證。
- ELRS 上板，可參考 `archive/x2201-carrier-v5`、`-v6`。
- OpenIPC 圖傳上板，v5 有 Thinker 影像板 + BL-M8812EU2 的電路可參考。
- 計圈和陀螺儀沿用階段 1。

v6 的教訓：一次整合太多，初版風險過高。所以開始前要先分別驗證電調、ELRS、圖傳這幾塊，最後才合成一塊。馬達雜訊對射頻和影像的干擾、散熱也要先評估。
