# X2201 電路板路徑

終極目標是 ALL IN ONE：電調、ELRS、OpenIPC 圖傳、計圈全部做在一塊板上。

做法是先把已有、已跑通的東西整合起來，每一步只驗證一件新事情。

| 階段 | 內容 | 狀態 |
|---|---|---|
| 0 接線驗證 | 不打板，用 S3 開發板接線 | 全部通過（2026-11-13） |
| 1 主板 | 電池只進主板。板載電調（DRV8874）、板載 5V BEC（約 2–2.5A）、SuperMini 控制器，另接 EP2、舵機、圖傳、陀螺儀、IR，按鈕開關機 | 2026-11-17 在 JLC 下單，等板子回來測試 |
| 2 ALL IN ONE | ELRS、OpenIPC 圖傳上板，和階段 1 合成一塊 | 目標，尚未設計 |

## 階段 0：接線驗證

驗證的路徑是 EP2 → CRSF → S3 → PWM → 電調。2026-11-13 全部通過：訊號線全接、一起上電，EP2 不會卡死。

原本卡死的原因是 EP2 的 TX 焊盤直接接到電調的第 1 路，電調開機時把它拉低。改成 EP2 只接 S3 的輸入腳後，這個問題就不存在了。

## 階段 1：主板

元件和電路見 [PLAN.md](PLAN.md)，板子是 [`x2201-mainboard`](x2201-mainboard)。板子外形可以照車內實際空間調整，元件和接線以 PLAN.md 為準。

過關條件：裝車後每次上電都能用，前進、煞車、倒車和轉向都正常，陀螺儀讀得到，IR 能被終點拱門辨識。按鈕能正常開機和關機，關機後馬達不出力。

## 階段 2：ALL IN ONE

等階段 1 完成才開始，這裡只記方向。

- 電調、5V BEC、計圈、陀螺儀沿用階段 1。
- ELRS 上板（SX1280 + AT2401C）。`lib/` 留著這幾顆的符號和封裝。
- OpenIPC 圖傳上板（Thinker 影像板 + BL-M8812EU2）。

舊的嘗試已從目錄刪除，需要時可以從 git 找回：`git show 56bd000:hardware/archive/x2201-carrier-v5/...`。v5 畫過 ELRS 和 OpenIPC 的電路；v6 把 S3 晶片、天線全做在板上，教訓是一次整合太多，初版風險過高。所以開始階段 2 前，要先分別驗證 ELRS 和圖傳，最後才合成一塊。馬達雜訊對射頻和影像的干擾、散熱也要先評估。
