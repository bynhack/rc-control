# X2201 載板 v8（ESP32-S3-MINI-1 + EP2）

46.3×34.5 mm，2 層，1.6 mm，單面零件，4 個 M2 不鍍銅孔（孔距 41.8×29.5）。

功能：**讓 EP2 上電就能工作、接線、電池電量偵測、計圈**，並接上圖傳 UART，供電量和圈速 OSD 使用。

接法：

- `電池 → 電調 → 馬達、舵機`（主電源，和原本一樣）
- `EP2 → PWM → 電調`：EP2 的 TX 焊盤是 S1（轉向），RX 焊盤是 S2（油門），經板子直接到 J1，不經過 S3，S3 當機也不影響開車
- `電調 BEC 5V → J1 → 板子`；EP2 的 5V 由 Q1 延遲約 0.5～1 秒才送出，等電調放開 EP2 的 TX 焊盤後再開機，這就是上電卡死的解法
- `電池 → Y 線 → J6`：細線分一路給電量偵測和圖傳，不是電調的主電源

EP2 要維持 **PWM 模式**。

## 下單

| 項目 | 內容 |
|---|---|
| PCB | 上傳 `x2201-carrier-v8-gerber.zip`：2 層、1.6 mm、1 oz |
| SMT | 上傳 `bom.csv`、`cpl.csv`，單面貼片。EP2 不貼 |
| 另買 | EP2 2400RX 一個；ZH1.5 4P ×1（電調）、ZH1.5 2P ×3、電池 Y 線；要外接 EP2 再加 ZH1.5 4P ×1（圖傳用原裝 JST1.0 6P 線） |

貼片前請在嘉立創的預覽裡確認 U1、U3 和 MOS 的方向。

## 手焊

只有 EP2，三種裝法擇一（不要同時用）：

- **焊盤朝上緣**：板上焊盤由左到右 G / 5V / RX / TX，天線朝板中央。
- **焊盤朝下**：板上焊盤由左到右 TX / RX / 5V / G，天線朝板子上緣，訊號通常較好。
- **插線**：EP2 接線到 J2，放到車上訊號好的位置。

貼板時 EP2 零件面朝上平放，四個半孔對齊焊盤（間距 2.4 mm），用烙鐵逐個點焊。**焊前依名稱核對 EP2 上的絲印，不要只看位置**。

## 接法

| 位號 | 類型 | 腳位 |
|---|---|---|
| J1 電調 | ZH1.5 4P | 1 S2 黃、2 S1 藍、3 GND 綠、4 5V 棕 |
| J2 EP2 外接 | ZH1.5 4P | 1 EP2 TX（S1）、2 EP2 RX（S2）、3 延遲 5V、4 GND |
| J3 圖傳 | SH1.0 6P | 1 電源、2 GND、3 圖傳 RX、4 圖傳 TX，5、6 不接 |
| J4 風扇 | ZH1.5 2P | 1 5V、2 GND，電調一開就轉 |
| J5 IR | ZH1.5 2P | 1 LED+、2 LED− |
| J6 電池 | ZH1.5 2P | 1 VBAT、2 GND |

電池的主線仍接電調。J6 用 Y 線分一路過來，供電壓偵測和圖傳使用；板子的 5V 由電調 BEC 經 J1 供給。
| J9 | USB-C | 燒錄與除錯 |

圖傳的電池電源由電調的 5V 控制（Q2、Q3）：電調開關關掉，圖傳也會斷電。

| GPIO | 功能 |
|---|---|
| 9 | 電池電壓（×22/122） |
| 10 / 11 | 圖傳 UART RX / TX |
| 15 | IR |

S3 不在控制鏈路上，空著的 GPIO 可以之後再用。

板子左上角的 B、G 兩個焊盤用來救磚：用鑷子短接 B 和 G，同時上電，就進入下載模式。

## 第一次上電

1. 電池先不接，插上電調線，從上往下看 J1 應是棕、綠、藍、黃。
2. 用萬用表確認 J6 的正負極。
3. 上電後 EP2 應在約 1 秒內開始閃燈，然後連上發射端。
4. D2、D3 隔開 USB 和電調 BEC，可以同時插。只插 USB 時，EP2、圖傳、風扇和 IR 都沒有電。

## 重新產生

```bash
/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 gen_pcb.py
```

佈線用 `../tools/freerouting-1.9.0.jar`；沒有這個檔案時加 `REUSE_SES=1`，沿用已存的 `.ses`。`FAB=1` 同時輸出 Gerber、BOM 和座標檔，之後再跑 `gen_sch.py` 更新原理圖。
