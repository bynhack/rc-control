# X2201 主板 v9（階段 1，舊電源方案）

**不要打板。** 2026-11-13 決定階段 1 把有刷電調做在主板上，不外掛電調；BEC 用本板這顆 5V 3A 降壓，供應 1–3A。本目錄的電調仍是外接焊盤，電池銅皮也是按外接大電流電調畫的。訊號、插座、GPIO 和 U4 降壓可以沿用，見 [ROADMAP.md](../ROADMAP.md)。

49×38 mm，2 層，1.6 mm，單面零件，4 個 M2 不鍍銅孔（孔距 44×33）。

電池接到主板，主板再接外接電調、舵機、EP2 和圖傳。電調只負責驅動馬達，可以換成任何標準有刷電調，例如 MINI30A。

## 接法

```
電池 → W1/W2 → Q1 防反接 ─┬→ W3/W4 → 外接電調 → 馬達
                           ├→ U4 5V 3A 降壓 → S3、EP2、舵機、風扇、IR
                           └→ 電量偵測、圖傳（S3 控制開關）
EP2 ─CRSF→ J2 → S3 ─┬─ PWM → P2 舵機
                    └─ PWM → P1 電調訊號
陀螺儀 LSM6DS3TR-C ─I2C→ S3
```

- **防反接 Q1**：N-MOS 放在電池負極，導通電阻約 5.5 mΩ。電池接反時整台車都斷開，**連電調也受保護**。
- **5V 由主板供應**：電調的 BEC 不接（P1 第 2 腳空著），避免兩個 5V 互相打架。
- **只插 USB 時**：S3 和 EP2 有電，可以直接調試；舵機、風扇、IR、圖傳沒有電。
- **EP2 的 TX 焊盤只接 S3 的輸入腳**，原本上電卡死的條件不存在。

## 焊接

板上零件全部貼片。要自己焊的只有：

| 位號 | 內容 |
|---|---|
| W1 BAT+、W2 BAT− | 電池線，外側一排（標示 BAT） |
| W3 ESC+、W4 ESC− | 電調電源線，內側一排（標示 ESC） |
| P1、P2 | 2.54 mm 3 針排針 |

焊線孔孔徑 1.25 mm，適合 20 AWG 左右的線。**焊電池前用萬用表確認正負極**：上排是 +，下排是 −。

## 插座

| 位號 | 類型 | 腳位 |
|---|---|---|
| P1 電調訊號 | 2.54 3P 排針 | 1 訊號、2 不接（電調 BEC）、3 GND |
| P2 舵機 | 2.54 3P 排針 | 1 訊號、2 5V、3 GND |
| J2 EP2 | ZH1.5 4P | 1 EP2 TX、2 EP2 RX、3 5V、4 GND |
| J3 圖傳 | JST1.0（SH）6P | 1 電源、2 GND、3 圖傳 RX、4 圖傳 TX，5、6 不接 |
| J4 風扇 | ZH1.5 2P | 1 5V、2 GND，接上電池就轉 |
| J5 IR | ZH1.5 2P | 1 LED+、2 LED− |
| J9 | USB-C | 燒錄與除錯 |

排針第 1 腳是方形焊盤。

## GPIO

| GPIO | 功能 |
|---|---|
| 6 | 圖傳電源，高電位開，重開機時關閉 |
| 7 | 電調油門 PWM（10k 下拉：S3 重開機時電調收不到脈衝，馬達停住） |
| 8 | 舵機 PWM |
| 9 | 電池電壓（×22/122） |
| 10 / 11 | 圖傳 UART RX / TX |
| 13 / 14 | CRSF RX / TX |
| 15 | IR |
| 16 / 17 / 18 | 陀螺儀 SDA / SCL / INT（I2C 位址 0x6A） |

油門、舵機、CRSF 的腳位和 `firmware/elrs-bench` 相同。B、G 兩個焊盤用來救磚：短接 B 和 G 同時上電，進入下載模式。

## 設計說明

- **主電流路徑**：電池焊盤到電調焊盤之間，正負極都用雙面覆銅連接，不經過細走線。電流上限依電調規格（30A，峰值 40A）設計，但 500 mAh 電池實際能持續供應的電流遠低於此。
- **降壓**：LMR51430，輸出 5.0V（0.6V × (1 + 22k/3k)），電感 4.7µH。EN 在晶片底下直接接 VIN，接地走晶片底下的過孔，SW 往外繞到電感：這幾段是手畫的，見 `gen_pcb.py` 的 `HAND_T`。
- **舵機**：插座旁有 22µF 電容，吸收舵機用力時的電流突波。
