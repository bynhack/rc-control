# X2201 硬體方案

2026-11-16 確認。這份文件只寫元件和電路，**不綁定板子外形**：主板的大小、零件擺位、插座朝向，可以照車內實際空間調整，只要元件和接線照這份做。目前照這份畫好的板子是 [`x2201-mainboard`](x2201-mainboard)（40×40 mm）。

## 車上的東西

| 部件 | 型號 | 接到主板哪裡 |
|---|---|---|
| 馬達 | 260 有刷馬達 | J7，ZH2.0 2P |
| 電池 | 2S 鋰電（7.4V，500 mAh） | BAT+ / BAT− 焊盤，主板唯一的電源入口 |
| 舵機 | 17g 三線舵機 | P2，ZH1.5 3P |
| 接收機 | EP2 2400RX（ELRS，CRSF 輸出） | J2，ZH1.5 4P；或直接焊在 J8（車尾板邊的 4 個排針孔） |
| 圖傳 | Walksnail Avatar Ascent Lite+（3.0–12.6V，MSP UART） | J3，ZH1.5 4P |
| 風扇 | 25 mm，5V | J4，ZH1.5 2P |
| 計圈 IR | 940 nm IR LED，3 mm 直插 | D6，直接焊在主板車尾板邊 |
| 電源按鈕 | 不自鎖按鈕（按一下開、再按一下關） | J6，ZH1.5 2P |

不外接電調，ZERO-Z 和成品電調模組都不用。所有插座都是側插，插口朝外，板子上方只有 IR LED 立起來（也可以折平朝車尾）。

## 電源路線

```
電池 2S ── BAT+ ────────────┬─→ DRV8874 VM ──→ J7 → 馬達
          BAT− → Q1 → GND   ├─→ LMR51430（EN 由按鈕 / S3 控制）→ 5V
                            ├─→ Q2（S3 的 IO6 控制）→ 圖傳電源
                            └─→ 100k / 22k 分壓 → IO9（電量）
5V ─┬─→ D3 → SuperMini 5V 腳 → 板上 LDO → 3V3 → 陀螺儀、DRV8874 邏輯
    ├─→ D3 之後也接 EP2
    ├─→ 舵機、風扇、IR LED（33Ω 限流）
SuperMini 的 USB 5V 不會倒灌回主板的 5V（被 D3 擋住）
SuperMini 的 5V 腳就是它 USB 的 VBUS（原理圖），所以主板的 5V 一定要經過 D3 才接上去
```

- **電池只接主板一處**。電調、BEC、圖傳、電量偵測都從主板取電。
- **防反接 Q1**：低側 N-MOS（DMN3008SFG），放在電池負極。drain 接 BAT−，source 接主板 GND，gate 經 10k 接 BAT+。電池接反時，整塊板（包括電調）斷開。
- **BEC**：LMR51430 開關降壓，輸入 4.5–36V，輸出 5.0V（0.6V ×（1 + 22k/3k））。晶片標稱 3A，但電感 FXL0420-4R7-M 的飽和電流是 3A、額定 2.8A，所以 5V 實際能穩定供應約 2–2.5A。電感 4.7µH。不用線性穩壓：2S 滿電時每 1A 要燒掉約 3.4W，舵機一卡住 S3 就會掉電。
- **圖傳**：直接吃電池電壓，由 Q2（P-MOS）開關。S3 重開機時 IO6 為低，圖傳斷電。

## 電調

DRV8874（TI），PWM 模式。

| 項目 | 設定 |
|---|---|
| 控制 | IN1 = IO7、IN2 = IO4。10 前進、01 後退、11 煞車、00 惰行。兩腳都有內建下拉，S3 重開機時馬達處於惰行 |
| PMODE | 接 3V3（PWM 模式） |
| nSLEEP | 接 3V3：關機時沒有 3V3，晶片自動休眠 |
| 限流 | VREF 接 3V3，IPROPI 經 1.5k 接地：ITRIP = 3.3V ÷（450 µA/A × 1.5kΩ）≈ 4.9A |
| IMODE | 接地：固定關斷時間斬波，過流後自動重試 |
| 週邊 | VM：100nF + 22µF/25V。VCP–VM：100nF。CPH–CPL：22nF/50V |
| 散熱 | 底部散熱焊盤接地，焊盤下打導熱孔到背面地 |

選 DRV8874 的原因：有內建限流，以及過流、過熱、欠壓保護，JLC 可以直接貼。原本參考的 RZ7886 在立創只有 DIP-8，規格書也沒寫保護功能。

## 開關機

J6 接不自鎖按鈕，一端是電池，一端是 BTN。

- **開機**：按下時電池經 D4 拉高 BEC 的 EN，5V 起來，S3 開機。S3 的 TX（IO43）經 D5 接著拉住 EN，放開按鈕後仍維持開機。TX 在開機和重開機期間都是高電位，所以 S3 重開機不會斷電。按鈕要按住約 0.3 秒，等 S3 開機完成。
- **關機**：按下時，Q6 把按鈕狀態轉成 RX（IO44）上的低電位（用 S3 內建的上拉，約 45k，韌體要打開）。S3 偵測到後把 TX 拉低，放開按鈕就關機。
- EN 經 100k 下拉、100nF 濾波，避免 TX 開機時輸出的訊息誤觸。
- **D4 用 1N4148WS、R28 用 10k**，不用蕭特基二極體和 100k。開機後 TX 經 D5 把 EN 拉到約 3V，D4 承受約 3V 反壓。蕭特基（B5819WS）在 3V 反壓下漏電約 4µA（25°C）到約 40µA（75°C），流經 R28 到地。100k 時，BTN 在約 50°C 就會到 1.3V 左右，超過 Q6（AO3400）的開啟電壓（0.65–1.45V），RX 變低，韌體會以為按了關機。D4 離 DRV8874 只有 5 mm，板子一熱就會發生。1N4148WS 的漏電只有 nA 級，R28 改 10k 再多留一層餘量。按下按鈕時 1N4148 多約 0.5V 壓降，EN 仍有 6V 以上，開機不受影響。
- 關機後只剩分壓電阻（約 60 µA）和 DRV8874 的休眠電流在耗電。

## GPIO

| GPIO | 功能 |
|---|---|
| 13 / 12 | CRSF RX / TX（EP2） |
| 11 / 10 | 陀螺儀 SDA / SCL（LSM6DSV16X，I2C 0x6A，4.7k 上拉） |
| 9 | 電池電壓（×22/122，ADC1） |
| 8 | 舵機 PWM |
| 7 / 4 | 馬達 IN1 / IN2 |
| 6 | 圖傳電源，高電位開 |
| 5 | IR LED（經 AO3400） |
| 1 / 2 | 圖傳 UART TX / RX（經 1k） |
| 3 | 陀螺儀 INT |
| 43（TX） | 電源保持，高電位維持開機 |
| 44（RX） | 按鈕偵測，按下為低 |
| 48 | SuperMini 板上的 RGB LED |

SuperMini 板邊只有 IO1–13 和 TX/RX，IO14–18 沒有引出。EP2 的 TX 只接 S3 的輸入腳：階段 0 遇到的 EP2 開機卡死，原因就是它的 TX 被電調拉低。

## 備用控制器：微雪 ESP32-S3-Zero

手上還有一塊微雪 ESP32-S3-Zero 可以備用。外形一樣是 18 × 23.5 mm，每排 9 腳，2.54 mm 腳距，第一腳離 USB 那端 1.59 mm。兩排的間距略有不同：S3-Zero 的孔離側邊 1.38 mm（兩排相距 15.24），SuperMini 是 1.27 mm（15.46）。主板照 SuperMini 開孔，S3-Zero 每排只偏 0.11 mm，排針（0.64 mm 方針）插 1.0 mm 的孔還有餘量，焊得進去。

**但腳位定義不同，不能直接換上主板。** USB 朝上看：

| | 左排（從 USB 那端往下） | 右排 |
|---|---|---|
| SuperMini | TX、RX、1、2、3、4、5、6、7 | 5V、GND、3V3、13、12、11、10、9、8 |
| S3-Zero | 5V、GND、3V3、1、2、3、4、5、6 | TX、RX、13、12、11、10、9、8、7 |

5V、GND、3V3 在不同排，直接插上去 5V 會接到訊號腳。要改用 S3-Zero，主板要照它的腳序重新分配 GPIO、重新佈線。其他差異：板載 RGB LED 在 GP21（SuperMini 是 GP48）；陶瓷天線在遠離 USB 那端、靠 5V 那排；板載 LDO 是 ME6217（800mA）；背面另有 GP17、18、38–45 焊盤，用排針墊高就碰不到主板。

## 接口

| 位號 | 類型 | 腳位 |
|---|---|---|
| J2 EP2 | ZH1.5 4P 側插 | 1 EP2 TX、2 EP2 RX、3 5V、4 GND |
| J8 EP2 直焊 | 4 個 2.54 mm 排針孔，在車尾板邊 | 訊號同 J2，順序照 EP2 焊盤：1 GND、2 5V、3 EP2 TX、4 EP2 RX |
| J3 圖傳 | ZH1.5 4P 側插 | 1 電源（電池，Q2 開關）、2 GND、3 圖傳 RX、4 圖傳 TX |
| P2 舵機 | ZH1.5 3P 側插 | 1 訊號、2 5V、3 GND |
| J4 風扇 | ZH1.5 2P 側插 | 1 5V、2 GND |
| J6 按鈕 | ZH1.5 2P 側插 | 1 電池、2 BTN |
| J7 馬達 | ZH2.0（PH）2P 側插 | 1 OUT1、2 OUT2 |
| BAT+ / BAT− | 焊盤，鑽孔 1.15 mm | 20 AWG 電池線（線芯約 0.9 mm） |

要改的線材：圖傳原本是 SH1.0 6P 插頭，要改壓成 ZH1.5 4P；舵機要換成 ZH1.5 3P 插頭。

J7 的 PH2.0 額定 2A。馬達平常 1–3A，DRV8874 會把峰值限在約 4.9A，短時間沒問題；長時間大電流插頭會發熱。

## 韌體要做的事

- 開機後盡快把 TX（IO43）設成 GPIO 輸出高電位。關機時拉低，並等按鈕放開。
- RX（IO44）設成輸入並打開內建上拉（板上沒有上拉電阻），按下為低，要做去彈跳。
- 油門用 H 橋兩腳控制：前進時 IN1 PWM、IN2 低；後退時相反；煞車兩腳都高；惰行兩腳都低。
- IR（IO5）只能用 LEDC 或 RMT 送 38 kHz 的 burst，不能讓它長時間保持高電位：常亮時 R6（33 Ω、0805，額定 1/8 W）會燒到約 0.4 W，LED 也超過 100 mA。照應答器的發送方式，平均只有約 0.05 W。
- **陀螺儀是 LSM6DSV16X**（ST，C5267406），I2C 位址 0x6A，INT1 接 IO3。它是原本 LSM6DS3TR-C 的新一代，腳位相容，封裝和佈線都沒變；陀螺儀雜訊 2.8 mdps/√Hz（LSM6DS3TR-C 約 5）。暫存器和 LSM6DS3 不同，用 ST 官方的 lsm6dsv16x 驅動。2、3 號腳接地，類比輸入（analog hub）和 Qvar 功能不能打開。開機讀不到 0x6A 時要跳過陀螺儀功能，不能卡住。
- **關機的順序**：拉低 TX 後，先關掉欠壓偵測（brownout），用 `gpio_hold` 把 IO43 鎖在低電位，再進 deep sleep 等斷電。原因：5V 掉電途中 S3 如果被欠壓重開，TX 會回到高電位，經 D5 又把 EN 拉高，板子會自己再開機。這點要實測。
- **只插 USB、沒接電池時**：TX 經 D5 會把 LMR51430 的 EN 拉到約 3V，但它的 VIN 是 0V，超過規格書的絕對最大值（EN ≤ VIN + 0.3V）。IO9 讀到沒有電池時，要立刻把 TX 拉低；沒電池時也不要開圖傳（IO6）。燒錄時盡量接著電池。下一版會在 D5 串電阻根治，見主板 README。
- **電池接著時插 USB**：整塊板會開機，電調也是通電的，馬達可能會動，燒錄時把車架空。

## 已驗證和未驗證

- 已驗證（階段 0，2026-11-13）：EP2 → CRSF → S3 → PWM 這條路，EP2 只接 S3 時不會開機卡死。
- 未驗證：BEC、DRV8874、按鈕開關機、Q1 防反接，都還沒有實機上電過。
- SuperMini 的尺寸、腳序、天線位置已和原廠資料（2025-10 的尺寸圖、原理圖）核對：兩排相距 15.46 mm（每個焊盤有兩個孔，排針走靠內那個，離側邊 1.27 mm），第一腳離 USB 那端 1.60 mm，USB-C 伸出模組約 2.2 mm，天線在遠離 USB 那端、靠 TX/RX 那排。
