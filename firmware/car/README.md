# car

X2201 主板的韌體（ESP32-S3 SuperMini，`hardware/x2201-mainboard`）。電路和腳位見 [hardware/PLAN.md](../../hardware/PLAN.md)，之後的 WiFi、MQTT、OTA 見 [docs/platform-plan.md](../../docs/platform-plan.md)。

## 做什麼

| 模組 | 內容 |
|---|---|
| `power.c` | 開機第一件事把 TX（IO43）拉高保持電源；按住按鈕 0.8 秒關機（RX，IO44，用內建上拉）。關機時拉低 TX、關掉欠壓偵測、鎖住腳位，再進 deep sleep 等斷電 |
| `crsf.c` | UART1 420000 baud 收 EP2 的 CRSF：通道（0x16）、連線品質（0x14）；回傳電池電壓（0x08），方向盤儀表看得到 |
| `drive.c` | 舵機（IO8，50 Hz，988–2012 µs）；DRV8874（IO7/IO4，20 kHz slow decay）。照一般車用電調：前進；前進中往後拉是剎車；回中立 0.1 秒後再往後拉才倒車；中立是滑行。收不到通道 0.3 秒就滑行、轉向回中 |
| `battery.c` | IO9 讀電池（×122/22）。沒有電池（只有 USB）就放掉電源保持；低於斷電電壓 2 秒就斷油門，回升 0.2 V 才恢復 |
| `ir.c` | IO5 用 RMT 發計圈幀，和 `firmware/transponder` 一樣（38 kHz、1/3 佔空比、T = 400 µs、車號加反碼），拱門照樣讀得到 |
| `imu.c` | LSM6DSV16X（I2C 0x6A）讀偏航角速度。開機不校正，怎麼拿、怎麼放都可以：零點存在 NVS，車子只要靜止 1 秒（油門放開、角速度穩定）就自動更新。全新的板子第一次靜止前沒有零點，陀螺儀輔助先不作用。讀不到陀螺儀就不用 |
| `led.c` | SuperMini 板上的 WS2812 彩色燈（GPIO48）：綠 = 有訊號；藍閃 = 沒訊號；紅閃 = 電量低、斷油門；白閃（很暗）= 只有 USB 供電 |
| `console.c` | USB 串口指令，見下面 |
| `settings.c` | 設定存在 NVS |

CRSF 通道和方向盤控制器一致：通道 1 轉向、通道 2 油門。

## 編譯和燒錄

```bash
. ~/esp/esp-idf/export.sh
cd firmware/car
idf.py build
idf.py -p /dev/cu.usbmodemXXXX flash
```

分區表（`partitions.csv`）照平台計畫：兩個 1.94 MB 的 OTA 程式區加當機紀錄。開機程式已經開了 OTA 回滾。韌體目前約 300 KB。

## USB 串口指令

用任何串口工具連 SuperMini 的 USB（115200），一行一個指令：

| 指令 | 作用 |
|---|---|
| `status` | 電池、訊號、通道、輸出、陀螺儀、設定 |
| `watch [秒]` | 每 0.2 秒印一行即時數值，預設 5 秒 |
| `car <1-15>` | 紅外車號 |
| `limit <0-100>` | 油門上限（%） |
| `gyro <0-100>` | 陀螺儀輔助轉向的強度（%），0 = 關 |
| `gyrorev <0\|1>`、`motorrev <0\|1>`、`steerrev <0\|1>` | 反轉陀螺儀、馬達、舵機的方向 |
| `ir <0\|1>`、`vtx <0\|1>` | 紅外、圖傳電源開關 |
| `cutoff <mV>` | 斷電電壓（整包，預設 6000 = 每顆 3.0 V） |
| `off`、`reboot`、`version` | 關機、重開機、版本 |

設定會存進 NVS，重開機後還在。

## 裝上車後要下的設定

2026-11-24 用 2 號車在 X2201 車架上實測，每台裝上車後都要下：

```
steerrev 1
gyrorev 1
```

- 車頭往左轉（從上看逆時針）時，陀螺儀讀到正值。`gyrorev 1` 讓前輪往右反打。
- 輔助強度 `gyro <0-100>` 開車實測後再定。
- 轉向中心在 P4 方向盤上調，車上不調。
- 開機不用做任何動作。陀螺儀零點會在車子靜止時自動更新，`status` 的 gyro 那行看得到目前的零點。

## 板上另一顆藍燈

SuperMini 右上角還有一顆**藍燈**，那是板上鋰電池充電晶片（TP4054）的充電指示燈，不歸韌體控制。SuperMini 的 BAT 焊盤沒接電池時，充電晶片會反覆偵測，藍燈就一直閃。主板不接 BAT 焊盤，所以裝上車後藍燈照樣會閃，這是正常的。有些批次沒焊充電電路，藍燈就不會亮（2026-11-20 的第二塊就是這樣）。
