# ELRS 模組方案實測

驗證 **EP2 → CRSF → ESP32-S3 → PWM → 電調** 這條鏈路。

> 載板 v8 最終採用 EP2 直接 PWM 接電調，S3 不在控制鏈路上，**這份韌體不適用於 v8**，保留作為之後做 CRSF 方案的參考。
同一份韌體可用在 ESP32-S3-Zero 和 S3 開發板（狀態燈兩種板子的腳位都會驅動）。

## 接線

| EP2 焊盤 | ESP32-S3 | 備註 |
|---|---|---|
| TX | GPIO13 | S3 收 CRSF |
| RX | GPIO14 | S3 發 CRSF |
| 5V | 5V | 焊盤標示以 EP2 本體絲印為準 |
| G | GND | |

| 電調線 | ESP32-S3 | 備註 |
|---|---|---|
| 藍 S1（轉向） | GPIO8 | |
| 黃 S2（油門） | GPIO7 | |
| 綠 GND | GND | 只要接電調就一定要接 |
| 棕 5V | 只有測試 4 才接 | 其他測試不要接 |

**用杜邦線直接接模組時，USB 和電調 5V 絕對不能同時接。** S3-Zero 原理圖上，5V 腳與 USB VBUS 是直通的，中間沒有二極體。
焊在載板 v8 上則不受此限，D2、D3 會隔開。

## 準備

1. EP2 目前是 PWM 設定，要改回 CRSF。EP2 只接 5V 和 GND，等 60 秒，電腦連上 `ExpressLRS RX` WiFi：

   ```bash
   python3 ep2_serial.py
   ```

   會先在本目錄存備份。要改回 PWM（車子回到原本接法）時，同樣連上它的 WiFi 後執行 `python3 ep2_serial.py restore`。

2. 燒錄（見最後一節），開監看視窗。

3. 打開方向盤控制器和 ELRS 發射端，綁定短語要一致。ELRS 接收機**連上發射端之前不會送任何資料**。

## 測試

抬起車輪再接電調。

| # | 做法 | 通過標準 |
|---|---|---|
| 1 EP2 開機 | 只接 EP2 和 USB，發射端先關。上電後看 EP2 的 LED | LED 慢閃（等待發射端），不是一上電就恆亮 |
| 2 CRSF | 打開發射端，轉方向盤、踩油門 | 狀態「正常」，CH1/CH2 跟著動，`CRC錯` 不持續增加 |
| 3 接電調訊號 | 電調接 S1、S2、GND，電調接電池，**棕線不接**。重複上電 10 次 | 每次 EP2 都能連上；電調能解鎖；關掉發射端後 200 ms 內油門回中位 |
| 4 裝車實測 | **先拔 USB**，電調棕線接 5V，裝進車殼合上，開到你平常會跑的最遠處和車殼遮擋最多的角度，繞 5 分鐘 | 最遠處 `斷線=0`、最低 LQ 建議 ≥ 70 |

測試 4 結束後，先斷電池，拆掉棕線，再插 USB，開機第一行 `[上次]` 就是這次的記錄（每 10 秒存一次）。

### 狀態燈

| 燈 | 意義 |
|---|---|
| 滅 | 沒有連線 |
| 藍 | LQ ≥ 90 |
| 白 | LQ 70–89 |
| 白色閃爍 | LQ < 70 |

## 燒錄

```bash
. ~/esp/esp-idf/export.sh
```

```bash
idf.py -p /dev/cu.usbmodemXXXX flash monitor
```

S3-Zero 找不到序列埠時：按住 B，按一下 R，放開 B，再燒錄。開發板的兩個 USB 口都能看記錄。

## 這個韌體不驗證的事

- GPIO14 → EP2 RX（S3 送資料給接收機）只送電池和 ping 幀。`回覆` 增加表示雙向通，不增加則無法判定，因為不是每個 ELRS 版本都會回 ping。
