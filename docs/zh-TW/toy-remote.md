# 改裝玩具遙控器

[English](../en/toy-remote.md) | **繁體中文** | [简体中文](../zh-CN/toy-remote.md)

很多玩具遙控車沒有標準接收機，車只認自己的遙控器。這個改裝讓 P4 代替你的手去操作那個遙控器，遙控器再照原本的方式發給車，所以車本身完全不用改。

已驗證：極客者 X2201 的 JC-02T-2.4G 遙控器。只要遙控器的方向和油門各用一個電位器，都可以照同樣的方法改。

## 原理

遙控器的晶片讀的是每個電位器中間腳（滑動端）的電壓，範圍在電源和地之間。MCP4728 DAC 改由它把這個電壓送到晶片的那隻腳，電壓由 P4 透過 I2C 設定。遙控器跟 DAC 吃同一個 3V3，所以電壓跟原本電位器給的比例一致。

```
方向盤 → P4（駕駛模型、操控）→ I2C → MCP4728 → 遙控器晶片 → 2.4 GHz → 車
```

## 材料

| 材料 | 說明 |
|---|---|
| MCP4728 四路 DAC 模組 | 位址 0x60。用其中兩路：A 方向，B 油門 |
| PH2.0 4P 插座和插頭 | 裝在遙控器上，走 3V3、GND、VA、VB |
| 3PDT 撥動開關（3 刀 2 位） | 切換遙控器接 P4，還是接它自己的電位器和電池 |
| 細導線 | 訊號電流很小 |

## 建議做法：插座加切換開關

加了插座和開關，遙控器還能完全照原樣單獨使用：撥到「原裝」裝電池，或撥到「P4」插上線。開關讓 DAC 和電位器不會同時接著，電池和 P4 的 3V3 也不會接在一起。

| 開關的刀 | 公共端（遙控器板子） | 「原裝」位置 | 「P4」位置 |
|---|---|---|---|
| 1 | 晶片的方向輸入（方向電位器的焊盤） | 方向電位器的中間腳 | 插座 VA |
| 2 | 晶片的油門輸入（油門電位器的焊盤） | 油門電位器的中間腳 | 插座 VB |
| 3 | 板子的電池正極輸入 | 電池盒正極彈片 | 插座 3V3 |

插座的 GND 直接接遙控器的地，不經過開關。

### 步驟

1. **把每個電位器的中間腳跟它的焊盤分開。** 把中間腳拆焊後翹起來，或者割斷焊盤出去的走線。分開後，焊盤是晶片的輸入，那隻腳是電位器的輸出。兩邊的腳不要動。
2. **把電池正極分開。** 把電池盒正極的線從板子上拆下來：這條線接開關的「原裝」位置，它原本的焊盤接公共端。
3. 照上表接開關。
4. 把插座和開關裝在遙控器外殼上。
5. 做 P4 那一端的線：DAC 上排的 VA／VB／VCC／GND 接到插頭，見 [DAC 接線](#dac-接線)。

> [!CAUTION]
> 遙控器接著 P4 的 3V3 時，絕對不要裝電池。電池和 3V3 會互相灌電，可能把 P4 燒壞。有切換開關就不會發生這種情況。

## 簡易做法：DAC 直接並聯

如果不想動刀，可以把 DAC 的輸出直接焊在電位器的中間腳上，跟電位器並聯。DAC 比電位器「力氣大」，電壓由它決定。測試用的那個遙控器就是這樣接的。

- **要裝電池單獨用遙控器之前**，把接到 DAC 的 4 條線全部拔掉：VCC、GND、VA、VB。先拔電源線，因為電池盒彈片接著 P4 的 3V3。VA、VB 也要拔，DAC 沒通電時可能把電位器的電壓往下拉。
- **由 P4 控制時**，遙控器上的方向輪和扳機保持在中間不要動。推到底時，電位器會直接頂著 DAC 的輸出，輸出會被拉偏。

## DAC 接線

| MCP4728 焊孔 | 接到 |
|---|---|
| 下排 VCC | P4 的 12 PIN 排針 **3V3** |
| 下排 GND、SCL、SDA | P4 I2C 端子的 GND、SCL、SDA |
| 下排 LDAC | GND（不接的話輸出不會更新） |
| 上排 VA | 方向：開關第 1 刀的「P4」位置，或方向電位器的中間腳 |
| 上排 VB | 油門：開關第 2 刀的「P4」位置，或油門電位器的中間腳 |
| 上排 VCC、GND | 遙控器的電源：開關第 3 刀的「P4」位置和地，或電池盒的正負極彈片 |

> [!WARNING]
> P4 I2C 端子的 VCC 是 5 V，不要接。DAC 模組上的 4.7k 上拉電阻接在它的 VCC，接 5 V 會把 I2C 匯流排拉到 5 V，整條匯流排（包括觸控）都會卡死。

板子上的 UART 端子（5 針 PH2.0）跟 I2C 端子長得很像。找不到 DAC 時，先確認線插的是 I2C 那個。

DAC 會把停止位置存進 EEPROM，所以 P4 還在開機時，車也不會動。

## 校準

玩具遙控器的方向輪和扳機只轉到電位器的一小段。**超出這一段，晶片會讀錯電壓**：測試用的遙控器，油門給 2.1 V 反而前進。所以韌體的輸出永遠不會超出量到的兩端。

每一路要量三個點：一邊到底、停止、另一邊到底。數值是 DAC 碼，0–4095 對應 0–3.3 V：

1. 打開[調試頁面](development.md#調試頁面)，連接 P4。
2. 在「精調 DAC」分頁，用滑鼠滾輪慢慢調每一路。記下車子兩邊打到底或跑到最快的碼，以及車剛開始動、剛停下的碼。停止點取車不動那一段的中間。
3. 把六個值寫進 [`main/remote.c`](../../firmware/wheel-esp32/main/remote.c) 開頭，再編譯燒錄：
   ```c
   #define STEER_LEFT 3320
   #define STEER_CENTER 2020
   #define STEER_RIGHT 660
   #define THR_REVERSE 1720
   #define THR_CENTER 1507
   #define THR_FORWARD 1320
   ```
4. 死區（停止點附近車不動的那一段）是那台車的[操控設定](driving.md#操控)，跟其他車一樣設。也可以在串口用 `dead <左> <右> <前進> <倒車>` 設，單位是千分比。

上面是 JC-02T 的數值。參考：X2201 用方向死區 138／132、油門死區 545／484（千分比）開起來剛好。
