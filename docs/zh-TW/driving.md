# 駕駛和操控

## 按鍵

| 功能 | MOZA R5 | T300RS | 說明 |
|---|---|---|---|
| 點火／熄火 | Start（36） | Start（10） | 只有掛 N 檔、兩個踏板都放開時才能點火 |
| 升檔／降檔：R N 1 2 3 | 右／左撥片（14／13） | 右／左撥片（2／1） | |
| 急停 | P（32） | 叉（3） | |
| 對頻 | N（19） | 三角（6） | 四合一串口模式 |

括號裡是 HID 按鍵編號，按下按鍵時狀態分頁會顯示它的編號。T300RS 的編號是照 Linux 驅動的報告格式推的，還沒在實機上確認；不對的話改 `main/main.c` 的 `BUTTONS`。

右踏板是油門，左踏板是剎車。

## 駕駛模型

駕駛模型在 `control.c`，照真車設計：

- 1／2／3 檔的最大動力是 33／67／100%，R 檔 40%。
- 只有在 R 檔踩油門才會倒車；換方向要先停車。
- 鬆開油門，車會慢慢滑行減速；剎車只負責剎車。
- 電調要設成「前進／剎車／倒車」模式。掛 R 檔時，韌體會自動送「剎車 → 回中 → 倒車」，電調才會真的倒車。
- 儀表盤上的車速是駕駛模型估算的，車上沒有測速。

### 安全規則

安全規則都在 `control.c`，任何發射方式都繞不過去：

- 開機時預設熄火。
- 300 ms 收不到方向盤的資料，方向和油門就回中並熄火；方向盤恢復後要重新點火。
- 急停一律讓方向和油門回中。

## 車輛

設定頁的第一個分頁「車輛」有 6 台車，點一下就換車。每台車各自記住：

- 發射方式和它的參數
- 最高車速（用來顯示 km/h）
- 引擎聲浪
- 「操控」分頁裡的所有設定

語言、音量、力回饋強度、螢幕翻轉和 ELRS 接法是控制器本身的設定，所有車共用。

## 操控

操控層在駕駛模型和發射方式之間，**所有發射方式都一樣**。每種發射方式只負責把最後的 −1…+1 換成自己的訊號：CRSF 通道、PPM、四合一通道或 DAC 電壓。以後加的新發射方式，也一樣要經過這些設定。

```
方向：方向盤 → 轉角 → 中心柔和 → 方向死區 → 方向回正 → 舵量 → 反轉 → 發射方式
油門：駕駛模型 → 油門死區 → 反轉 → 發射方式
```

| 設定 | 範圍 | 作用 |
|---|---|---|
| **方向盤轉角** | 90–900°，預設 900° | 方向盤轉到這個角度時車輪打死。再往外，力回饋用軟性頂點擋住方向盤；回正彈簧按 900／轉角 加強，最多 2.5 倍。越大越穩，越小越靈敏 |
| **中心柔和** | 0–80% | 方向盤中間一段轉向更細，直線更穩 |
| **方向死區** | 左、右各一個，最多 50% | 方向盤要先轉一點車輪才開始動時用。設好之後，方向盤一動車輪就跟著動 |
| **方向回正** | 最多滿舵的 30% | 像原廠遙控器的方向微調，給跑不直的車用 |
| **舵量** | 左、右各一個，滿舵的 30–100% | 打死的位置，避免舵機頂死，也讓左右對稱 |
| **油門死區** | 前進、倒車各一個，最多 80% | 電調中位附近車不動的那一段。輸出 = 死區 + 油門 ×（1 − 死區），一踩車就動，檔位只限制最高速度；剎車不受影響 |
| **反轉** | 每種發射方式各一組，在「發射設定」 | 反轉方向或油門 |

### 在車上設定

每一項都是車開著時，直接用方向盤或踏板設定：

- **方向死區**：按「用方向盤調」，從中間慢慢往左轉，車輪剛開始動時按「存左」；往右同樣，按「存右」。
- **方向回正**：按「用方向盤調」，把方向盤扶在車剛好走直線的位置，按「保存」。之後力回饋會把方向盤拉回正中。
- **舵量**：按「用方向盤調」，打到車輪剛好到底時按「存左」或「存右」。
- **油門死區**：按「用油門調」，掛 1 檔慢慢踩，車剛開始動就按「保存」；再掛 R 檔存一次倒車的。調的時候踏板直接輸出，最多 90%。

調某一項時，那一項本身暫時不生效，看到的是還沒加上它之前的位置。

## 力回饋

兩種底座都用同樣三個效果：

- 回正彈簧，隨車速加強
- 阻尼
- 第三個帶死區的彈簧，當作方向盤轉角的軟性頂點

MOZA R5 用標準 USB PID 效果，T300RS 用它自己的協議。T300 上韌體還會關掉底座自帶的回正彈簧，並把轉角設成 900°。

強度在「駕駛設定」分頁，預設 40%。報告怎麼送到底座，見[開發](development.md#力回饋)。

## 儀表盤和聲浪

- 兩套儀表盤：曜石、碳纖，左右滑動切換。
- 引擎聲浪由駕駛模型即時合成，不用錄音。有三種：普通轎車、拉力賽車、寶馬 M4，每台車各選一種。
