# 驾驶和操控

## 按键

| 功能 | MOZA R5 | T300RS | 说明 |
|---|---|---|---|
| 点火／熄火 | Start（36） | Start（10） | 只有挂 N 挡、两个踏板都放开时才能点火 |
| 升挡／降挡：R N 1 2 3 | 右／左拨片（14／13） | 右／左拨片（2／1） | |
| 急停 | P（32） | 叉（3） | |
| 对频 | N（19） | 三角（6） | 四合一串口模式 |

括号里是 HID 按键编号，按下按键时状态标签页会显示它的编号。T300RS 的编号是照 Linux 驱动的报告格式推的，还没在实机上确认；不对的话改 `main/main.c` 的 `BUTTONS`。

右踏板是油门，左踏板是刹车。

## 驾驶模型

驾驶模型在 `control.c`，照真车设计：

- 1／2／3 挡的最大动力是 33／67／100%，R 挡 40%。
- 只有在 R 挡踩油门才会倒车；换方向要先停车。
- 松开油门，车会慢慢滑行减速；刹车只负责刹车。
- 电调要设成“前进／刹车／倒车”模式。挂 R 挡时，固件会自动发“刹车 → 回中 → 倒车”，电调才会真的倒车。
- 仪表盘上的车速是驾驶模型估算的，车上没有测速。

### 安全规则

安全规则都在 `control.c`，任何发射方式都绕不过去：

- 开机时默认熄火。
- 300 ms 收不到方向盘的数据，方向和油门就回中并熄火；方向盘恢复后要重新点火。
- 急停一律让方向和油门回中。

## 车辆

设置页的第一个标签页“车辆”有 6 台车，点一下就换车。每台车各自记住：

- 发射方式和它的参数
- 最高车速（用来显示 km/h）
- 引擎声浪
- “操控”标签页里的所有设置

语言、音量、力回馈强度、屏幕翻转和 ELRS 接法是控制器本身的设置，所有车共用。

## 操控

操控层在驾驶模型和发射方式之间，**所有发射方式都一样**。每种发射方式只负责把最后的 −1…+1 换成自己的信号：CRSF 通道、PPM、四合一通道或 DAC 电压。以后加的新发射方式，也一样要经过这些设置。

```
方向：方向盘 → 转角 → 中心柔和 → 方向死区 → 方向回正 → 舵量 → 反转 → 发射方式
油门：驾驶模型 → 油门死区 → 反转 → 发射方式
```

| 设置 | 范围 | 作用 |
|---|---|---|
| **方向盘转角** | 90–900°，默认 900° | 方向盘转到这个角度时车轮打死。再往外，力回馈用软性顶点挡住方向盘；回正弹簧按 900／转角 加强，最多 2.5 倍。越大越稳，越小越灵敏 |
| **中心柔和** | 0–80% | 方向盘中间一段转向更细，直线更稳 |
| **方向死区** | 左、右各一个，最多 50% | 方向盘要先转一点车轮才开始动时用。设好之后，方向盘一动车轮就跟着动 |
| **方向回正** | 最多满舵的 30% | 像原厂遥控器的方向微调，给跑不直的车用 |
| **舵量** | 左、右各一个，满舵的 30–100% | 打死的位置，避免舵机顶死，也让左右对称 |
| **油门死区** | 前进、倒车各一个，最多 80% | 电调中位附近车不动的那一段。输出 = 死区 + 油门 ×（1 − 死区），一踩车就动，挡位只限制最高速度；刹车不受影响 |
| **反转** | 每种发射方式各一组，在“发射设置” | 反转方向或油门 |

### 在车上设置

每一项都是车开着时，直接用方向盘或踏板设置：

- **方向死区**：按“用方向盘调”，从中间慢慢往左转，车轮刚开始动时按“存左”；往右同样，按“存右”。
- **方向回正**：按“用方向盘调”，把方向盘扶在车刚好走直线的位置，按“保存”。之后力回馈会把方向盘拉回正中。
- **舵量**：按“用方向盘调”，打到车轮刚好到底时按“存左”或“存右”。
- **油门死区**：按“用油门调”，挂 1 挡慢慢踩，车刚开始动就按“保存”；再挂 R 挡存一次倒车的。调的时候踏板直接输出，最多 90%。

调某一项时，那一项本身暂时不生效，看到的是还没加上它之前的位置。

## 力回馈

两种底座都用同样三个效果：

- 回正弹簧，随车速加强
- 阻尼
- 第三个带死区的弹簧，当作方向盘转角的软性顶点

MOZA R5 用标准 USB PID 效果，T300RS 用它自己的协议。T300 上固件还会关掉底座自带的回正弹簧，并把转角设成 900°。

强度在“驾驶设置”标签页，默认 40%。报告怎么发到底座，见[开发](development.md#力回馈)。

## 仪表盘和声浪

- 两套仪表盘：曜石、碳纤，左右滑动切换。
- 引擎声浪由驾驶模型实时合成，不用录音。有三种：普通轿车、拉力赛车、宝马 M4，每台车各选一种。
- 界面有简体和繁体中文，在设置页右上角的“简体”／“繁體”切换。
