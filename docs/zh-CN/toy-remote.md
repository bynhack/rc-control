# 改装玩具遥控器

[English](../en/toy-remote.md) | [繁體中文](../zh-TW/toy-remote.md) | **简体中文**

很多玩具遥控车没有标准接收机，车只认自己的遥控器。这个改装让 P4 代替你的手去操作那个遥控器，遥控器再照原来的方式发给车，所以车本身完全不用改。

已验证：极客者 X2201 的 JC-02T-2.4G 遥控器。只要遥控器的方向和油门各用一个电位器，都可以照同样的方法改。

## 原理

遥控器的芯片读的是每个电位器中间脚（滑动端）的电压，范围在电源和地之间。MCP4728 DAC 改由它把这个电压送到芯片的那只脚，电压由 P4 通过 I2C 设置。遥控器跟 DAC 用同一个 3V3 供电，所以电压跟原来电位器给的比例一致。

```
方向盘 → P4（驾驶模型、操控）→ I2C → MCP4728 → 遥控器芯片 → 2.4 GHz → 车
```

## 材料

| 材料 | 说明 |
|---|---|
| MCP4728 四路 DAC 模块 | 地址 0x60。用其中两路：A 方向，B 油门 |
| PH2.0 4P 插座和插头 | 装在遥控器上，走 3V3、GND、VA、VB |
| 3PDT 拨动开关（3 刀 2 位） | 切换遥控器接 P4，还是接它自己的电位器和电池 |
| 细导线 | 信号电流很小 |

## 推荐做法：插座加切换开关

加了插座和开关，遥控器还能完全照原样单独使用：拨到“原装”装电池，或拨到“P4”插上线。开关让 DAC 和电位器不会同时接着，电池和 P4 的 3V3 也不会接在一起。

| 开关的刀 | 公共端（遥控器板子） | “原装”位置 | “P4”位置 |
|---|---|---|---|
| 1 | 芯片的方向输入（方向电位器的焊盘） | 方向电位器的中间脚 | 插座 VA |
| 2 | 芯片的油门输入（油门电位器的焊盘） | 油门电位器的中间脚 | 插座 VB |
| 3 | 板子的电池正极输入 | 电池盒正极弹片 | 插座 3V3 |

插座的 GND 直接接遥控器的地，不经过开关。

### 步骤

1. **把每个电位器的中间脚跟它的焊盘分开。** 把中间脚拆焊后翘起来，或者割断焊盘出去的走线。分开后，焊盘是芯片的输入，那只脚是电位器的输出。两边的脚不要动。
2. **把电池正极分开。** 把电池盒正极的线从板子上拆下来：这条线接开关的“原装”位置，它原来的焊盘接公共端。
3. 照上表接开关。
4. 把插座和开关装在遥控器外壳上。
5. 做 P4 那一端的线：DAC 上排的 VA／VB／VCC／GND 接到插头，见 [DAC 接线](#dac-接线)。

> [!CAUTION]
> 遥控器接着 P4 的 3V3 时，绝对不要装电池。电池和 3V3 会互相灌电，可能把 P4 烧坏。有切换开关就不会发生这种情况。

## 简易做法：DAC 直接并联

如果不想动刀，可以把 DAC 的输出直接焊在电位器的中间脚上，跟电位器并联。DAC 比电位器“力气大”，电压由它决定。测试用的那个遥控器就是这样接的。

- **要装电池单独用遥控器之前**，把接到 DAC 的 4 根线全部拔掉：VCC、GND、VA、VB。先拔电源线，因为电池盒弹片接着 P4 的 3V3。VA、VB 也要拔，DAC 没通电时可能把电位器的电压往下拉。
- **由 P4 控制时**，遥控器上的方向轮和扳机保持在中间不要动。推到底时，电位器会直接顶着 DAC 的输出，输出会被拉偏。

## DAC 接线

| MCP4728 焊孔 | 接到 |
|---|---|
| 下排 VCC | P4 的 12 PIN 排针 **3V3** |
| 下排 GND、SCL、SDA | P4 I2C 端子的 GND、SCL、SDA |
| 下排 LDAC | GND（不接的话输出不会更新） |
| 上排 VA | 方向：开关第 1 刀的“P4”位置，或方向电位器的中间脚 |
| 上排 VB | 油门：开关第 2 刀的“P4”位置，或油门电位器的中间脚 |
| 上排 VCC、GND | 遥控器的电源：开关第 3 刀的“P4”位置和地，或电池盒的正负极弹片 |

> [!WARNING]
> P4 I2C 端子的 VCC 是 5 V，不要接。DAC 模块上的 4.7k 上拉电阻接在它的 VCC，接 5 V 会把 I2C 总线拉到 5 V，整条总线（包括触控）都会卡死。

板子上的 UART 端子（5 针 PH2.0）跟 I2C 端子长得很像。找不到 DAC 时，先确认线插的是 I2C 那个。

DAC 会把停止位置存进 EEPROM，所以 P4 还在开机时，车也不会动。

## 校准

玩具遥控器的方向轮和扳机只转到电位器的一小段。**超出这一段，芯片会读错电压**：测试用的遥控器，油门给 2.1 V 反而前进。所以固件的输出永远不会超出量到的两端。

每一路要量三个点：一边到底、停止、另一边到底。数值是 DAC 码，0–4095 对应 0–3.3 V：

1. 打开[调试页面](development.md#调试页面)，连接 P4。
2. 在“精調 DAC”标签页，用鼠标滚轮慢慢调每一路。记下车子两边打到底或跑到最快的码，以及车刚开始动、刚停下的码。停止点取车不动那一段的中间。
3. 把六个值写进 [`main/remote.c`](../../firmware/wheel-esp32/main/remote.c) 开头，再编译烧录：
   ```c
   #define STEER_LEFT 3320
   #define STEER_CENTER 2020
   #define STEER_RIGHT 660
   #define THR_REVERSE 1720
   #define THR_CENTER 1507
   #define THR_FORWARD 1320
   ```
4. 死区（停止点附近车不动的那一段）是那台车的[操控设置](driving.md#操控)，跟其他车一样设。也可以在串口用 `dead <左> <右> <前进> <倒车>` 设，单位是千分比。

上面是 JC-02T 的数值。参考：X2201 用方向死区 138／132、油门死区 545／484（千分比）开起来刚好。
